# sawhserehuit-blip.github.io

Personal site, served by GitHub Pages at <https://sawhserehuit-blip.github.io>.

Plain HTML — a single `index.html` with its CSS inline. No build step, no
framework, no JavaScript. Edit the file, commit, push; Pages redeploys on its own.

- `index.html` — the whole site
- `.nojekyll` — serve files as-is, skipping Jekyll processing

Fonts (Bitter, JetBrains Mono) load from Google Fonts; everything else is local.
A print stylesheet is included, so the page prints as a clean one-page CV.
